# План правок главной страницы

## 1. Типографика — убрать «прыгающие» цифры
**Проблема:** Playfair Display italic для цен (CHF 1'499.00) даёт OldStyle-цифры — они скачут по базовой линии и сливаются.

**Решение:**
- Убрать `italic` со всех цен и акцентных цифр (Hero, разделы Prices).
- Цены вывести в `Inter` (sans-serif) с табулярными цифрами: `font-variant-numeric: tabular-nums`, weight 600, цвет золотой/navy.
- Заголовок Hero «Intensivecourse in 9 days for 1 person — only CHF 1'499.00» переписать в обычном (не italic) Playfair, уменьшить размер до `text-3xl md:text-5xl` и перебить строки так, чтобы строка с ценой помещалась полностью.
- Полностью убрать `italic` по всему файлу `src/routes/index.tsx`.

## 2. Ширина сетки — расширить всю страницу
**Проблема:** один блок (Hero) на всю ширину, остальные `max-w-4xl/5xl/7xl` — визуально страница «сжимается» к центру.

**Решение:** унифицировать контейнер на `max-w-6xl` (или `max-w-screen-xl` ≈ 1280px) для всех секций: Intro, Exam, Theory, One Week, Subscriptions, Individual, Footer. Боковые отступы `px-6 md:px-12`.

## 3. Фото Beat Lang
**Проблема:** на фото есть текст (подпись/водяной знак), цвета не в гамме сайта.

**Решение через `imagegen--edit_image`:**
- Источник: текущий `beat-lang.jpg` (CDN).
- Промпт: убрать любой наложенный текст/подписи (либо стереть, либо кадрировать), повысить чёткость, тонировать в тёплый navy+gold (приглушённая палитра под обложку с озером), сохранить реалистичность лица.
- Соотношение 3:2 горизонтальное.
- Сохранить → новый `.asset.json`, заменить ссылку в Intro.
